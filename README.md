# Customer Churn Analysis

This project performs exploratory data analysis (EDA) and feature preparation
on a Telco Customer Churn dataset using Python.

## Objectives
- Understand customer churn patterns
- Perform data cleaning and preprocessing
- Generate insights using visualizations
- Prepare features for machine learning models

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Structure
- `Customer_Churn_analysis.ipynb` – main analysis notebook
- `data/` – dataset or dataset reference
